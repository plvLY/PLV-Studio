## 1. 视觉方向

采用 Editorial Tech Portfolio 风格：干净浅色背景、深色文字稳定对比、蓝色作为主要交互色、青绿色仅用于少量辅助强调；清晰网格、细边框、克制阴影与足够留白，以真实项目内容为视觉中心。

2026-11 视觉升级在保持方向不变的前提下，为「核心数据」与「行动路径」补了两类视线锚点：

- **首屏右侧**：终端风格作品预览框（悬停上浮、截图微缩放大），两种主题下都使用深色框体，形成开发者工作台的视觉记忆点。
- **首屏左侧**：Live Stats 数据胶囊（大号数字 + 核心项目状态），数字来自内容集合与进度数据，不手工维护。

## 2. 设计令牌

浅色：背景 `#F7F8FA`、卡片 `#FFFFFF`、次级表面 `#EEF2F7`、主文字 `#172033`、次级文字 `#526075`、弱化文字 `#5A687D`、边框 `#E2E8F0`、主色 `#1D4ED8`、辅助强调 `#0F766E`、成功 `#166534`、警告 `#854D0E`。

暗色：背景 `#0B1120`、卡片 `#111827`、次级表面 `#172033`、主文字 `#F3F4F6`、次级文字 `#9CA3AF`、弱化文字 `#98A6BC`、边框 `#293548`、辅助强调 `#2DD4BF`。

语义令牌统一在 CSS 变量中管理并映射暗色模式，不允许在组件中散落不同的颜色值。

> 状态必须配合文字标签，不允许仅通过颜色表达状态。

## 3. 交互组件

- **首屏终端框体**：`.hero-window`，悬停上浮与截图缩放；`prefers-reduced-motion` 下关闭位移与缩放。
- **Live Stats 胶囊**：移动端 2×2、桌面 4 列数据格；状态格使用文字 + 圆点，不只靠颜色。
- **能力标签页**：CapabilityExplorer，同一时间只展开一个方向；无 JS 时标签退化为锚点，全部面板保持展开可读。
- **作品横滑带**：移动端 scroll-snap 横向滑动，桌面端两列网格；滑动容器可键盘聚焦。
- **发布日志**：ChangeList 按 ✨ 新功能 / 🐛 修复 / ⚡ 性能 / 📝 文档 / 🔧 工程 分组；ReleaseBadge 标注 `[Released]` / `[In Progress]` / `[Planned]`。
- **架构图**：Markdown 中的 Mermaid 在构建期渲染为静态 SVG；移动端宽图只在图内横向滚动。

## 4. 页面改造范围

- **首页**：定位与真实项目预览 → Live Stats → 按身份分流 → 精选作品（主案例 + 更多作品横滑带）→ 能力与证据标签页 → 发布日志式最近更新 → 带真实实例链接的六阶段流程
- **作品列表/详情**：统一卡片与状态体系；详情按「架构速览 → 项目概览 → 设计文档 → 开发与发布 → 验收与上线」组织阅读路径，并提供移动端目录；有技术方案的作品在概览前展示静态架构图
- **文档页**：统一长文排版（正文约 720–820px）、代码/表格/图表横向滚动不撑破页面；桌面端固定目录、移动端可展开目录，附上一篇/下一篇与返回路径
- **关于页**：技术主线、能力与公开证据（同一套标签页）、项目记录方式与公开入口分组呈现；外部仓库明确标注为外部证据

## 5. 验收要点

- 状态、日期、作品名称均来自统一数据源
- 不显示虚构截图、空按钮与无效链接；规划内容明确标注
- 响应式覆盖 360px 至宽屏；键盘可操作、焦点可见、对比度达 WCAG AA
- 项目详情与文档页不出现整页横向滚动；移动端目录与正文不互相挤压
- 无 JS 时：能力面板全部可见，正文与文档可完整阅读
