## 1. 视觉方向

采用 Editorial Tech Portfolio 风格：干净浅色背景、深色文字稳定对比、蓝色作为主要交互色、青绿色仅用于少量辅助强调；清晰网格、细边框、克制阴影与足够留白，以真实项目内容为视觉中心。

## 2. 设计令牌

页面背景 `#F7F8FA`、卡片 `#FFFFFF`、主文字 `#172033`、次级文字 `#64748B`、边框 `#E2E8F0`、主色 `#2563EB`、辅助强调 `#0F9488`；语义令牌统一在 CSS 变量中管理并映射暗色模式，不允许在组件中散落不同的颜色值。

> 状态必须配合文字标签，不允许仅通过颜色表达状态。

## 3. 页面改造范围

- **首页**：定位与真实项目预览 → 站点速览 → 精选作品（完整案例卡）→ 能力与证据 → 最近开发记录 → 通用开发流程（明确不代表项目状态）
- **作品列表/详情**：统一卡片与状态体系；详情按「项目概览 → 设计文档 → 开发进度 → 验收与上线」组织阅读路径，并提供移动端目录
- **文档页**：统一长文排版（正文约 720–820px）、代码/表格横向滚动不撑破页面；桌面端固定目录、移动端可展开目录，附上一篇/下一篇与返回路径
- **关于页**：技术主线、能力与公开证据、项目记录方式与公开入口分组呈现；外部仓库明确标注为外部证据

## 4. 验收要点

- 状态、日期、作品名称均来自统一数据源
- 不显示虚构截图、空按钮与无效链接；规划内容明确标注
- 响应式覆盖 360px 至宽屏；键盘可操作、焦点可见、对比度达 WCAG AA
- 项目详情与文档页不出现整页横向滚动；移动端目录与正文不互相挤压
