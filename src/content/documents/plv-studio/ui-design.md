## 1. 视觉方向

采用 Editorial Tech Portfolio 风格：干净浅色背景、深色文字稳定对比、蓝色作为主要交互色、青绿色仅用于少量辅助强调；清晰网格、细边框、克制阴影与足够留白，以真实项目内容为视觉中心。

## 2. 设计令牌

页面背景 `#F7F8FA`、卡片 `#FFFFFF`、主文字 `#172033`、次级文字 `#64748B`、边框 `#E2E8F0`、主色 `#2563EB`、辅助强调 `#0F9488`；语义令牌统一在 CSS 变量中管理并映射暗色模式，不允许在组件中散落不同的颜色值。

> 状态必须配合文字标签，不允许仅通过颜色表达状态。

## 3. 页面改造范围

- **首页**：定位介绍 → 代表作品 → 真实进展 → 能力证据 → 工作方法
- **作品列表/详情**：统一卡片系统；详情按「概览 → 当前状态 → 文档 → 进度 → 技术实现」组织阅读路径
- **文档页**：统一长文排版（正文约 720–820px）、代码/表格横向滚动不撑破页面、返回路径清晰
- **关于页**：技术能力分组并关联真实作品

## 4. 验收要点

- 状态、日期、作品名称均来自统一数据源
- 不显示虚构截图、空按钮与无效链接；规划内容明确标注
- 响应式覆盖手机至大屏；键盘可操作、焦点可见、对比度达 WCAG AA
